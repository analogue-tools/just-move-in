## 1. Roles (lightweight)

| Role | Owns | Does not own alone |
|---|---|---|
| **Product** | Problem framing, constraints, P0 spine, Later backlog triage | Final event bus, final visual system, partner contracts |
| **Engineering** | Feasibility, events, adapters, cascade, ops console MVP | What we promise movers without product sign-off |
| **Design** | Language, Story columns, surface composition, a11y | Shipping false status for polish |
| **Sales / Partnerships** | Partner narrative, economics, report needs | Features that break watching / confirm / cascade |
| **CS / human-agent ops** | Escalation playbook, distress, capacity | Burying human escape for conversion |

## 3. Working rhythm (proposed)

1. **Kickoff**, Approach + Product non-negotiables (30-45 min)  
2. **Research playback**, Primary + secondary; label n=12 bias  
3. **Spine walk**, Demo P0 path only  
4. **Parallel tables**, Eng events · Design Story · Sales claims reconciled  
5. **Later triage**, Theme by theme from [08](08-LATER-DISCUSS.md); none forgotten, none accidentally P0  
6. **Spike**, Watching + confirm + cascade + Day 0 capture before Market polish  

---

## 4. Decision rules

- If it breaks watching, false confirm, cascade integrity, or human escape → **no**  
- If it is stickiness / ads / packing / votes → **Later** unless it unblocks learning  
- If evidence is thin (n=12) → decide with labelled assumption, instrument to learn  

---

## 5. What I need from the room

- Eng: reality-check adapters and receipt model  
- Design: push back where calm operator tone is weak  
- Sales: what partners will not buy / will over-promise  
- CS: where the customer support human agent actually burns time today  

Then we lock P0 and keep Later explicit.
