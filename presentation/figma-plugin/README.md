# Jay · Feature walkthrough (Figma plugin)

Creates page **`01 Narrative · Jay`**: wireframe phone beside What / Purpose / Design rationale / Research / Next.

## Run

1. Open your Just Move In Figma file.
2. **Plugins → Development → Import plugin from manifest…**
3. Pick this folder’s `manifest.json`.
4. **Plugins → Development → Jay · Feature walkthrough**
5. **Present** the new page.

Requires Inter (bundled with Figma). Offline; no network.
